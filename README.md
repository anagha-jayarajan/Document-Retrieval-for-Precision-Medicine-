# Document-Retrieval-for-Precision-Medicine-
This notebook creates a complete pipeline for biomedical information retrieval for the TREC 2019 Precision Medicine Track.The pipeline mimics the multi-layered process of Liu et al. that progresses from basic keyword matching to a deep learning ensemble for reranking.
Pipeline Architecture:
Two phases comprise the system. In Phase 1 (Initial Retrieval), a cascade of text normalization transforms (lowercasing, numeric display (token) substitution, stop-word removal, Porter stemming, and biomedical entity normalization via a local CTD/NCBI gene synonym database) occurs. This is followed by query expansion and weighted query boosting (with weights of 3× [disease/gene], 2× [treatment], and 1× [demographics]). The initial candidate set is produced using an BM25Okapi index. Phase 2 (Re-ranking) implements two deep-learning models that complement each other. BiGRU-Att (Bidirectional GRU with Attention) classifies the focus of the treatment. To capture the semantic matching in the disease dimension, a MatchPyramid model uses a 2D CNN coupled with dot product embedding in a query-document interaction matrix. The results of both models, in conjunction with the output from BM25, are combined via a Logistic Regression ensemble (trained on TREC qrel-derived labels), to give the final ranking. 
Evaluation & Findings:
Standard TREC metrics (P@5, P@10, NDCG@5, NDCG@10) measure performance over three structured patient queries across a 20 document PubMed-style corpus containing relevance annotations. An ablation study describes the addition of query expansion, boosting, classification, and relevance matching in order to assess the contribution of each component to the implementation. The BM25-only baseline was improved by all components; therefore, it was concluded that the full BM25 ensemble improves precision medicine retrieval.
